
# G+1 Commercial Building Construction — Primavera P6

## Project Overview

A Primavera P6 construction planning and scheduling project developed for a G+1 commercial building. The project demonstrates activity planning, WBS development, activity relationships, baseline management, resource loading, cost estimation, float analysis, and schedule variance analysis.

## Project Details

- **Software:** Oracle Primavera P6
- **Project Type:** G+1 Commercial Building
- **Planned Start:** 01 October 2026
- **Planned Finish:** 08 March 2027
- **Calendar:** 6-Day Construction Calendar
- **Total Resource-Loaded Cost:** ₹21.632 lakh
- **Baseline:** BL1

## Scope of Work

The schedule covers:

- Pre-Construction
- Earthwork
- Foundation
- Plinth Works
- RCC Structure
- Masonry
- Finishing
- MEP Works
- External Works
- Testing, Inspection & Handover

## Key Primavera P6 Work

- Developed a structured WBS and detailed activity schedule.
- Established Finish-to-Start and Start-to-Start activity relationships.
- Created and maintained a project baseline for schedule comparison.
- Assigned labour and equipment resources to construction activities.
- Developed a resource-loaded schedule and reviewed time-phased resource requirements.
- Assigned resource rates to estimate project resource costs.
- Analyzed total float and zero-float activities.
- Simulated an activity delay using relationship lag and performed schedule recovery.
- Compared current and baseline dates to evaluate schedule variance.
